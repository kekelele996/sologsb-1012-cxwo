# SignCourse Studio · 手语课程编排工具

SignCourse Studio 是面向手语教师的课程设计工作台。教师可以把示范片段、手形说明、字幕、镜头角度、常见错误和练习任务组合为学习步骤，并在手机和平板预览中检查字幕安全区、步骤依赖和替代文本。

## 功能

- 双窗口协作：课程在两个窗口各保留一份工作副本，模块一归属林老师、模块二归属赵老师；保存时只写回本窗口归属的模块切片，对方模块原样保留，两位老师同时保存互不覆盖。
- 归属与只读：模块带有负责老师，非归属模块在本窗口只读；未认领模块可由当前老师认领（先到先得），另提供访客只读身份。
- 跨模块学习路径：每个步骤可设置模块内前置，并可把其他模块（如模块一）的步骤选为模块二步骤的前置；引用集中登记在课程的引用表中。
- 引用挂起与确认：被引用步骤被对方老师删除或挪动、导致学习顺序倒挂时，引用自动挂起并通知引用方老师，由其确认保留（重新生效）或解除；挂起引用不参与阻断校验之外的路径计算。
- 离线编辑：断网时所有改动照常编辑并进入本窗口发件箱；网络恢复（或在同步中心手动触发）后按顺序幂等重放，已与课程一致的改动自动跳过、不重复写入，另一位老师的模块不受影响。
- 同步中心：查看在线/离线状态、共享文档修订号、待补回改动清单和挂起引用，并可模拟断网/恢复。
- 老数据迁移：首次打开自动把 v1 课程（无归属/引用）升级到 v2——模块按顺序归属两位老师、模块内前置保留、跨模块残留前置转成挂起引用待确认，老课程迁移后照常编辑，旧存储键保留作为备份。
- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，并运行带检查点的动作时间线。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、练习反馈不完整和常见错误缺失。
- 状态流转：支持草稿、提交复核、退回修改、冻结版本和基于冻结版本创建修订版。
- 离线编辑：所有修改保存在 `localStorage`（共享课程文档 + 每位老师各自的工作副本与发件箱）；浏览器离线或刷新后可继续编辑，恢复后自动补回。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + S` 保存草稿、`Alt + ↑/↓` 调整步骤顺序。

## 技术栈

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 数据模型（v2）

- `sologsb-1012-shared-course-v2`：两位老师共享的课程文档，保存动作以模块为切片合并。
- `sologsb-1012-local-<clientId>`：当前窗口（按老师身份）的工作副本。
- `sologsb-1012-outbox-<clientId>`：断网期间按序待补回的操作日志，重放幂等。
- 模块带 `ownerId` 归属；跨模块前置登记在 `references` 引用表中，含 `active / suspended` 状态。
- 旧键 `sologsb-1012-sign-course-project-v1` 在迁移后原样保留，作为备份。

核心逻辑位于 `src/collab.ts`（共享文档、切片合并、发件箱重放、引用核对）与 `src/models.ts`（v2 模型、校验、v1 迁移）。

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
